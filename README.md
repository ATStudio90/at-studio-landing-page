# AT Studio — Landing Page

Landing page jasa pembuatan website AT Studio (UMKM, perorangan, organisasi).

- Satu file statis: `index.html` (self-contained, tinggal dibuka di browser)
- Harga promo: Hemat Rp75.000 (dari Rp750rb), Bisnis Rp150.000 (dari Rp1,9jt), Premium Rp250.000 (dari Rp4,5jt)
- Nomor WhatsApp di tombol konsultasi & formulir masih placeholder — ganti sebelum disebar

## Publish ke GitHub Pages

1. Push repo ini ke GitHub
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, folder `/ (root)`
3. Buka `https://<username>.github.io/<repo>/`
